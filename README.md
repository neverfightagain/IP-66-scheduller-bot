# KPI Schedule Telegram Bot 🎓

Telegram-бот для академічної групи КПІ (за замовчуванням **ІП-66**, ID: `6084`), який автоматично надсилає:
1. ☀️ **Ранковий дайджест** о 08:00 (усі пари на день із посиланнями на Zoom/Meet).
2. 🔔 **Сповіщення за 5 хвилин** до початку кожної пари з поточним часом, назвою, викладачем та кнопкою швидкого переходу до відеоконференції.
3. 📌 **Команди на вимогу:**
   * `/today` — розклад на сьогодні.
   * `/tomorrow` — розклад на завтра.
   * `/week` — поточний тиждень (чисельник/знаменник) та київський час.
   * `/links` — список збережених посилань на Zoom/Meet.
   * `/subscribe` — увімкнути сповіщення в цьому чаті.
   * `/unsubscribe` — вимкнути сповіщення.
   * `/help` — список команд.

---

## 🚀 Швидкий запуск

### 1. Налаштування `.env`
Відкрийте файл `.env` та вкажіть ваш токен бота:
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
KPI_GROUP_ID=6084
TIMEZONE=Europe/Kyiv
MORNING_DIGEST_TIME=08:00
NOTIFY_MINUTES_BEFORE=5
```

### 2. Заповнення посилань на Zoom/Meet (`links.json`)
У файлі `links.json` уже підготовлені всі предмети вашої групи. Заповніть поле `"url"` (та за потреби `"comment"` з паролем чи ідентифікатором):
```json
"Лінійна алгебра та аналітична геометрія (Прак)": {
  "subject": "Лінійна алгебра та аналітична геометрія",
  "type": "Прак",
  "lecturer": "Новікова Юлія Вікторівна",
  "url": "https://us04web.zoom.us/j/...",
  "comment": "Пароль: 12345"
}
```

### 3. Запуск бота
```powershell
py bot.py
```

### 4. Додавання у групу Telegram
1. Додайте вашого бота в груповий чат Telegram.
2. Напишіть у групі команду `/start` або `/subscribe`.
3. Бот запам'ятає ID групи у файлі `chats.json` і почне автоматично надсилати сповіщення та дайджести.
